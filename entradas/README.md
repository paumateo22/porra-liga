# Buzón de pronósticos

Suelta aquí los ficheros `J02_Nombre.json` que te manden los jugadores y ejecuta:

    python main.py  ->  opción 2

Los válidos se archivan en `participantes/<slug>/pronosticos/` y el original se
mueve a `procesadas/`. Los rechazados se quedan aquí con el motivo impreso en consola.
